# 업다운 팬클럽

금샘탕을 운영하시는 강다운 사장님 비공식 팬클럽 페이지.
주접을 올리고, 공감하고, 댓글 달고, 팬미팅으로 질문을 넣는 곳입니다.

**금샘탕 공식 채널이 아닙니다.** 팬들이 만든 비공식 공간이에요.

---

## 무엇이 들어 있나

| | |
|---|---|
| `index.html` | 페이지 전체. HTML·CSS·JS가 한 파일에 들어 있고 빌드 과정이 없습니다. |
| `supabase/schema.sql` | 데이터베이스 스키마. 테이블·뷰·함수·권한 전부. |
| `supabase/README.md` | 수파베이스 연결 절차와 운영 안내. |
| `docs/design-spec.md` | 디자인 토큰, 레터링, 픽셀 캐릭터 SVG. |
| `docs/structure-spec.md` | 정보구조, 데이터 모델, 카피 확정본. |

## 기능

- **주접** — 글 올리고 공감하고 댓글 달기. 인기글은 공감·댓글에 시간 감쇠를 걸어 뽑습니다
- **인사해요** — 인사를 남겨야 글을 쓸 수 있습니다. 질문 네 개에 답하는 형식
- **팬미팅** — 사장님께 질문. 아이디당 하루 한 장
- **입덕 카운터** — 가입일 기준 며칠째인지. 한국 자정마다 오릅니다
- **활동 규칙** — 익명 공간 가이드라인 여덟 줄
- **범쨩** — 운영자 계정. 글 고정·숨김·삭제, 팬미팅 답변 옮겨 적기, 공지, 신고함

## 어떻게 돌아가나

페이지 하나가 두 가지 저장소를 쓸 수 있습니다.

- **Supabase** — `index.html` 의 `SUPABASE` 설정이 채워져 있으면 이쪽. 누구나 들어와서
  같은 글을 봅니다. 권한과 횟수 제한을 서버가 판정합니다
- **브라우저 저장** — 설정이 비었거나 서버에 못 닿으면 이쪽. 이 기기에서만 보입니다.
  페이지가 깨지는 대신 읽고 쓰는 건 되게 해두었어요. 푸터에 지금 어느 모드인지 뜹니다

### 데이터를 어떻게 지키나

테이블을 직접 열어주지 않는 게 설계의 축입니다.

- 모든 테이블에 RLS를 켜고 **정책을 하나도 두지 않아** 바깥에서는 아무것도 못 읽고 못 씁니다
- 읽기는 안전한 컬럼만 추린 **뷰**로만. 토큰과 PIN 해시는 어디에도 안 나갑니다
- 쓰기는 **security definer 함수**로만. PIN은 bcrypt로 서버에서 비교합니다
- 하루 한 장은 `(사람, 한국 날짜)` 유니크로, 공감 1인 1회는 복합 기본키로 강제합니다

그래서 `index.html` 에 박힌 anon 키가 공개돼도 남의 글을 지우거나 PIN을 캐낼 수 없습니다.
브라우저를 거치지 않고 서버로 직접 요청해도 같은 거부가 돌아옵니다.

**다만 만능은 아닙니다.** 4자리 PIN은 경우의 수가 1만이고 서버 쪽 시도 횟수 제한이 없습니다.
가입 자체에도 제한이 없어서 닉네임을 대량으로 만드는 도배는 막지 못해요.
자세한 내용과 대응은 `supabase/README.md` 에 적어뒀습니다.

## 띄우기

1. 수파베이스 프로젝트를 만들고 `supabase/schema.sql` 을 SQL Editor 에서 실행
2. `index.html` 의 `SUPABASE.url` 과 `SUPABASE.anonKey` 를 채우기
3. 아무 정적 호스팅에나 올리기 (GitHub Pages, Vercel, Netlify)

절차는 `supabase/README.md` 에 자세히 있습니다.

## 만든 것

디자인은 금샘탕 도감 포스터에서 색을 뽑아 토큰으로 정리했고, 대제목은 금샘탕 로고의
파랑·빨강 조합을 따랐습니다. 화면은 90년대 오락실 감성의 픽셀 스킨 한 종입니다.
